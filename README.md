## Executive Overview

The transition to electric vehicles in India is hindered by significant consumer friction:
1. **Range and Operating Uncertainty**: Difficulty reconciling real-world degradation, passenger payload, air conditioning load, and regional topography against certified range figures.
2. **Total Cost of Ownership (TCO) Ambiguity**: Complex calculations involving state-specific subsidies, tiered electricity tariffs, and battery lifecycle expectations versus internal combustion engine (ICE) benchmarks.
3. **Fragmented Dealer Networks**: Coordinating test drives across distinct original equipment manufacturers (OEMs) typically requires visiting multiple disjointed physical dealerships.
4. **Dealer Onboarding Inefficiency**: Dealerships and commercial vendors frequently abandon complex digital onboarding workflows.

EasyEV solves these challenges by deploying a connected multimodal intelligence stack:

```text
Natural Voice Discovery (Hindi / Hinglish / English)
        |
        v
Realtime Conversational AI Pipeline (Sub-300ms Barge-In)
        |
        v
Deterministic Buyer Decision Passport (Context Engine)
        |
        v
Streamable Model Context Protocol (MCP) Decision Tools
        |
        v
Interactive Visual Deal Room & 3D Virtual Showroom Stage
        |
        v
Verified CRM Integration, Calendar Sync, and Dealership Test Drive
```

## Core Technological Innovations

### 1. Agora Real-Time Voice Pipeline & Multi-Tier Audio Stack

The EasyEV voice experience is built upon **Agora's Conversational AI and Real-Time Communication (RTC/RTM) infrastructure**, which delivers the sub-second responsiveness required for high-stakes automotive discovery:

* **Agora Conversational AI Engine**: Direct integration with Agora's real-time edge processing for full-duplex conversational audio, ultra-low packet loss over unstable mobile networks, and sub-300ms barge-in latency.
* **Intelligent Voice Activity Detection (VAD)**: Dual client-side and server-side VAD enabling immediate speech interruption without clipping or delayed cutoff.
* **Synchronized Real-Time Messaging (Agora RTM 2.x)**: Concurrently streams vehicle specification cards, range map coordinates, and stage transitions synchronized to spoken turns.
* **Sarvam AI Neural Hindi TTS**: Integration of Sarvam AI `bulbul:v3` supporting male Hindi speakers (`shubh`, `aditya`, `rahul`) with authentic regional cadence.
* **Microsoft Azure Neural Speech**: High-reliability fallback utilizing `hi-IN-MadhurNeural` and `hi-IN-AaravNeural`.
* **OpenAI Voice Services**: Multilingual synthesis fallback for specialized operational modes.

### 2. Sarvam AI Indic Neural Voice Synthesis Engine

To serve Indian EV buyers authentically across Hindi and Hinglish dialects, EasyEV incorporates **Sarvam AI's Sovereign Indic Speech Engine (`bulbul:v3`)** integrated directly into the Agora conversational agent voice processing pipeline:

* **Vernacular Accent & Vocabulary Precision**: Conventional TTS engines frequently mispronounce Indian automotive terms, state subsidy nomenclature, and colloquial units (*"lakh"*, *"on-road price"*, *"15A 3-pin socket"*, *"FAME-II"*, *"range anxiety"*). Sarvam AI delivers natural Indian prosody, cadence, and phonetically accurate pronunciation.
* **Calm Automotive Advisory Persona**: The default male voice (`shubh`) is tuned for an empathetic, consultative tone that builds buyer trust during high-stakes financial calculations and battery life evaluations.
* **Dynamic Experience Pacing (1.08x vs 0.88x)**: The pipeline dynamically modulates the voice pace:
  * **1.08x Pace**: Deployed in the **Live Consultation Room** and **3D Showroom Guide** for energetic, fluid, and quick conversational turns.
  * **0.88x Pace**: Deployed in the **Dual-AI Debate Arena** for deliberate, measured, and authoritative argumentative delivery.
* **Speaker Customization**: Fully configurable across 20+ Indic male speaker profiles (`shubh`, `aditya`, `rahul`, `rohan`, `amit`, `dev`, `ratan`, `varun`, `manan`, `sumit`, `kabir`, `aayan`, `ashutosh`, `advait`, `anand`, `tarun`, `sunny`, `mani`, `gokul`, `vijay`, `mohit`, `rehan`, `soham`) via the `SARVAM_TTS_SPEAKER` environment variable.
* **Live System Health Diagnostics (`/api/ready`)**: The server continuously monitors and exposes Sarvam API readiness, selected voice persona, and target model (`bulbul:v3`) over the `/api/ready` diagnostic endpoint.
* **Seamless Multi-Tier Fallback**: When Sarvam credentials are not supplied, the platform falls back seamlessly to Microsoft Azure Neural Voice (`hi-IN-MadhurNeural`) and OpenAI TTS (`onyx`) without restarting or dropping active sessions.

```javascript
// Native SarvamTTS integration and bulbul:v3 subclass in server.mjs
import { SarvamTTS, MicrosoftTTS, OpenAITTS } from 'agora-agents';

// agora-agents defaults to bulbul:v2 without exposing custom params.
// We subclass SarvamTTS to explicitly inject model: 'bulbul:v3' and custom pace into Agora cloud:
class SarvamV3TTS extends SarvamTTS {
  toConfig() {
    const config = super.toConfig();
    return { ...config, params: { ...config.params, model: 'bulbul:v3' } };
  }
}

function sarvamTts(pace) {
  return new SarvamV3TTS({
    key: SARVAM_API_KEY,
    speaker: SARVAM_TTS_SPEAKER, // Default: 'shubh'
    targetLanguageCode: 'hi-IN',
    pace,                        // 1.08 for consultation/showroom, 0.88 for debate
    sampleRate: 24000,
  });
}

// Multi-tier voice selection per session:
const tts = language !== 'English' && SARVAM_TTS_READY
  ? sarvamTts(isDebate ? 0.88 : 1.08)
  : AZURE_SPEECH_READY
    ? new MicrosoftTTS({ azureKey: AZURE_SPEECH_KEY, region: AZURE_SPEECH_REGION, voiceName: 'hi-IN-MadhurNeural' })
    : new OpenAITTS({ apiKey: OPENAI_API_KEY, voice: 'onyx' });
```

### 5. Realistic Physics Range Derating & Thermal Impact Engine

Commercial EV brochures in India routinely quote standard test-cycle ranges (ARAI / MIDC) that diverge significantly from real-world Indian road and climate realities. EasyEV incorporates a deterministic multi-factor derating engine that computes expected real-world range ($R_{\text{real}}$):

$$R_{\text{real}} = R_{\text{claimed}} \times \eta_{\text{temp}} \times \eta_{\text{speed}} \times \eta_{\text{payload}} \times \eta_{\text{terrain}}$$

Where:
* **$R_{\text{claimed}}$**: ARAI or MIDC certified laboratory range in kilometres.
* **$\eta_{\text{temp}}$ (Thermal & Climate Coefficient)**: Captures HVAC auxiliary electrical load and battery electrochemical degradation under extreme ambient temperatures:
  $$\eta_{\text{temp}} = \begin{cases} 0.76 & \text{Extreme Summer } (T_{\text{amb}} \ge 42^\circ\text{C with continuous cabin AC cooling}) \\ 0.88 & \text{Moderate Summer / Monsoon } (28^\circ\text{C} \le T_{\text{amb}} < 42^\circ\text{C with intermittent AC}) \\ 0.96 & \text{Optimal Ambient } (20^\circ\text{C} \le T_{\text{amb}} < 28^\circ\text{C, minimal climate load}) \\ 0.82 & \text{Northern Winter } (T_{\text{amb}} < 10^\circ\text{C, cold battery impedance}) \end{cases}$$
* **$\eta_{\text{speed}}$ (Aerodynamic & Velocity Factor)**: Models quadratic aerodynamic drag ($F_{\text{drag}} \propto v^2$) on Indian highways versus congested urban crawls:
  * Pure Stop-and-Go City Traffic ($v_{\text{avg}} \approx 22\text{ km/h}$, high regenerative braking recovery): $\eta_{\text{speed}} = 1.05$
  * Mixed Urban-Ring Road ($v_{\text{avg}} \approx 45\text{ km/h}$): $\eta_{\text{speed}} = 0.95$
  * Expressway / Highway Cruising ($v_{\text{avg}} \ge 90\text{ km/h}$, sustained high motor draw): $\eta_{\text{speed}} = 0.74$
* **$\eta_{\text{payload}}$ (Mass & Incline Factor)**: Standardized for 4-wheelers ($75\text{ kg}$ driver baseline) derated by $-2.5\%$ per additional passenger ($+65\text{ kg}$) or luggage cargo ($+50\text{ kg}$). For 3-wheelers (Euler HiLoad, Treo Plus), derates linearly up to $-18\%$ at maximum certified gross vehicle weight (GVW).

### 6. Deterministic Total Cost of Ownership (TCO) & Payback Math

The `/mcp` `calculate_ownership` decision tool executes multi-variable financial amortization models contrasting EV purchase and operation against internal combustion engine (ICE) benchmarks:

$$\Delta \text{Cost}_{N} = \left( \text{CapEx}_{\text{EV}} + \sum_{t=1}^{N} \frac{\text{OpEx}_{\text{EV}, t}}{(1 + r)^t} \right) - \left( \text{CapEx}_{\text{ICE}} + \sum_{t=1}^{N} \frac{\text{OpEx}_{\text{ICE}, t}}{(1 + r)^t} \right)$$

$$\text{OpEx}_{\text{EV}, t} = \text{AnnualKm} \times \left( \frac{\text{kWh}}{100\text{km}} \times \frac{\bar{T}_{\text{elec}}}{100} \right) + \text{AnnualService}_{\text{EV}}$$

$$\text{OpEx}_{\text{ICE}, t} = \left( \frac{\text{AnnualKm}}{\text{Mileage}_{\text{ICE}}} \times P_{\text{fuel}} \right) + \text{AnnualService}_{\text{ICE}}$$

Where:
* **Blended Electricity Tariff ($\bar{T}_{\text{elec}}$)**:
  $$\bar{T}_{\text{elec}} = (\alpha_{\text{home}} \times T_{\text{home}}) + ((1 - \alpha_{\text{home}}) \times T_{\text{public}})$$
  * $T_{\text{home}}$: State DISCOM residential slab rate (default: INR 7.50 / kWh).
  * $T_{\text{public}}$: CPO public fast-DC tariff (default: INR 18.00 / kWh).
  * $\alpha_{\text{home}}$: Buyer home charging split fraction (default: $0.80$).
* **Equated Monthly Installment (EMI)**:
  $$\text{EMI} = P \times r \times \frac{(1 + r)^n}{(1 + r)^n - 1}$$
  Where $P = \text{ExShowroom} \times (1 - \text{DownPaymentRate})$, $r = \text{AnnualInterest} / 1200$, and $n = \text{TenureYears} \times 12$.
* **Break-Even Amortization Horizon ($T_{\text{break-even}}$)**:
  $$T_{\text{break-even}} = \frac{\text{CapEx}_{\text{EV}} - \text{CapEx}_{\text{ICE}}}{\text{AnnualSavings}_{\text{OpEx}}} \text{ (years)}$$

## API Reference

The EasyEV server exposes standardized HTTP and REST endpoints:

### Multimodal Consultation Sessions
* `GET /api/session/token`: Issues authenticated Agora RTC/RTM tokens for the client.
* `POST /api/session/start`: Initializes a conversational AI session with language, persona, and prejoin context.
* `POST /api/session/think`: Triggers tool execution requests and updates session generation counters.
* `POST /api/session/interrupt`: Signals immediate audio cut-off and cancels pending asynchronous tool executions.
* `POST /api/session/stop`: Cleans up active Agora sessions and finalizes the Buyer Decision Passport.

### Virtual 3D Showroom
* `GET /showroom/`: Serves the 3D Showroom application.
* `GET /showroom-assets/*`: Delivers progressive 360-degree vehicle image sequences and Pannellum cubemaps.
* `GET /api/vehicle-session/token`: Generates session tokens for product-specific showroom guides.
* `POST /api/vehicle-session/start`: Instantiates a voice guide configured with vehicle-specific specifications.

### Compare Arena & Dual-AI Debates
* `GET /api/debate-session/token`: Allocates RTC tokens for dual-AI debate channels.
* `POST /api/debate-session/start`: Launches an automated vehicle debate between two advocate models.

### Dealer Onboarding & Directory
* `GET /api/dealers`: Lists registered and verified dealerships with filtering by city and brand.
* `GET /api/dealers/stats`: Aggregates active dealer counts, coverage cities, and supported categories.
* `POST /api/dealers/register`: Processes manual dealer registration requests.
* `GET /api/dealer-session/token`: Provides authentication tokens for the dealer voice copilot.
* `POST /api/dealer-session/start`: Starts a conversational voice session for dealership onboarding.
* `POST /api/dealer-session/process-turn`: Submits recognized speech turns to the dealer onboarding FSM.
* `POST /api/dealer-session/submit`: Validates complete onboarding submissions and triggers confirmation emails.
* `GET /api/dealer-session/telemetry`: Retrieves session diagnostics and completion progress.

### Test-Drive Booking Engine
* `GET /api/test-drive-session/token`: Issues tokens for the in-browser test-drive booking agent.
* `POST /api/test-drive-session/start`: Launches a test-drive scheduling voice agent.
* `POST /api/test-drive-session/process-turn`: Processes conversational slot selections and user contact details.
* `POST /api/test-drive/check-availability`: Programmatically queries slot availability for a specified date and location.
* `POST /api/test-drive/book`: Finalizes bookings, updates the local database, and dispatches confirmation emails.
* `POST /api/test-drive/initiate`: Triggers an automated outbound scheduling workflow (via Bland AI integration).
* `POST /api/bland/post-call`: Webhook receiver for automated telephony call outcomes.

### Human Specialist Console & Escalations
* `GET /rep` or `GET /rep.html`: Serves the specialist console.
* `GET /api/handoff/waiting`: Lists active consultation sessions awaiting human intervention.
* `POST /api/handoff/take`: Assigns an awaiting consultation session to an authenticated specialist.
* `GET /api/handoff/status`: Polling endpoint for clients to detect specialist assignment.

### Model Context Protocol (MCP)
* `POST /mcp`: Handles standard JSON-RPC 2.0 Streamable HTTP MCP initialization and tool invocation requests.

> [!IMPORTANT]

> 1. TLS 1.3 encryption is active with a valid SSL certificate.
> 2. WebSockets and SSE streams are passed without aggressive buffering (`proxy_buffering off;`).
> 3. Outbound UDP ports `10000-65535` are open for Agora SD-RTN edge audio media streaming.

## Security

EasyEV enforces enterprise-grade security protocols across conversational endpoints, authentication, and external integration layers:

### 1. Digital Personal Data Protection (DPDP) Act 2023 Compliance Matrix

EasyEV adheres to the Indian Digital Personal Data Protection (DPDP) Act 2023 across all customer-facing voice, camera, and geospatial touchpoints:

| DPDP Statutory Principle | Regulatory Requirement | EasyEV Architectural Implementation |
| :--- | :--- | :--- |
| **Purpose Limitation** | Data processed strictly for declared intent | Microphone and camera streams activate only upon explicit user gesture; deactivated immediately upon session termination. |
| **Data Minimization** | Collect only data necessary for discovery | Voice audio is streamed directly over Agora WebRTC buffers. **No raw user voice recordings are ever persisted to disk or external cloud buckets.** |
| **Storage Limitation** | Purge ephemeral data immediately | Parking and electrical snapshot image buffers are cryptographically zero-filled (`snapshot.buffer.fill(0)`) in memory immediately after vision classification completes. |
| **Consent Architecture** | Explicit, verifiable, withdrawable consent | Browser geolocation and camera access require affirmative user opt-in via interactive on-screen consent modals before tool invocation. |
| **PII Redaction & Sanitization** | Prevent accidental leakage to external LLMs | Spoken phone numbers, PAN identifiers, and GST numbers are parsed, normalized, and masked before prompt construction. |
| **Right to Erasure** | Delete data upon request | Users can purge their active Decision Passport and associated CRM deal draft instantly via the reset control or `DELETE /api/session/:id`. |

### 2. Cryptographic HMAC-SHA256 Tool Authentication

Every tool invocation dispatched to `/mcp` is verified against an HMAC-SHA256 digest using a timing-safe comparison to prevent timing attacks:

```javascript
// Timing-safe cryptographic HMAC-SHA256 validation in server.mjs
import { createHmac, timingSafeEqual } from 'node:crypto';

export function verifyMcpSignature(rawBody, clientSignature, secret) {
  if (!clientSignature || !secret) return false;
  const expectedSignature = createHmac('sha256', secret)
    .update(rawBody)
    .digest('hex');
  const clientBuf = Buffer.from(clientSignature, 'hex');
  const expectedBuf = Buffer.from(expectedSignature, 'hex');
  if (clientBuf.length !== expectedBuf.length) return false;
  return timingSafeEqual(clientBuf, expectedBuf);
}
```

### 3. Agora Dynamic Token Authentication & Channel Isolation

RTC and RTM session tokens are generated on the server using `agora-token` with strict 24-hour expiration windows and channel-level access grants. Channel identifiers are cryptographically randomized UUIDs, preventing unauthorized eavesdropping or channel traversal across consultation rooms.

## Known Limitations

1. **Browser HTTPS Requirement**: Browsers block microphone capture over insecure HTTP on non-localhost hosts. Production deployments must run behind a verified HTTPS domain.
2. **Hardware Audio Capture**: Conversational voice sessions require an active microphone input device; systems lacking audio input fall back to text-only mode.
3. **Cal.com Rate Limits**: Calendar slot synchronization relies on Cal.com API rate limits; high-frequency automated testing should utilize the mock slot generator.
4. **Third-Party Model Latency**: While Agora RTC latency remains sub-300ms, overall response speed depends on external LLM inference and TTS provider response times.

## Troubleshooting

| Issue | Root Cause | Resolution |
| :--- | :--- | :--- |
| **Microphone NotAllowedError** | Browser denied microphone permission | Click the lock/tune icon in the browser address bar, set Microphone to "Allow", and refresh the page. |
| **Port 4173 in use (EADDRINUSE)** | A previous node server instance is still running | Run `lsof -i :4173` and terminate the orphaned process with `kill -9 <PID>`, then restart `npm start`. |
| **Agora Token Error (401 / 403)** | Missing `AGORA_APP_ID` or `AGORA_APP_CERTIFICATE` | Verify that your `.env` contains valid credentials from the Agora Developer Console. |
| **Sarvam Voice Inactive (Fallback)** | `SARVAM_API_KEY` is missing or empty | The server automatically falls back to Microsoft Azure Speech or OpenAI TTS. Add a valid Sarvam key to activate `bulbul:v3`. |
| **MCP 403 Invalid Signature** | `MCP_SIGNING_SECRET` mismatch | Ensure `MCP_SIGNING_SECRET` is defined in `.env` and matches between the dispatcher and MCP transport. |
| **Deal Room Map Isochrone Missing** | Network block on OSM Overpass API | Verify internet connectivity to OpenStreetMap and OpenChargeMap endpoints. |
