2. Problem, idea, impact
Takeaway: EV adoption is a decision-confidence problem.
Pain: scattered facts; real-life fit is hard to calculate; generic sales answers reduce trust.
Product: multilingual voice AI that explains, compares, simulates and safely negotiates across scooters, cars, e-rickshaws and fleets.
Flow: confusion → natural conversation → verified next action.
Impact: buyer confidence and access.
Business: qualified leads and higher conversion.

3. Implementation and Agora
Architecture: Buyer UI → Agora real-time conversation → EasyEV decision/tool layer → verified data and actions.
Agora responsibilities: RTC audio, Conversational AI Engine, interruption/turn handling, RTM state sync, transcripts/session history/metrics, Sarvam ASR/TTS.
EasyEV responsibilities: decision graph, evidence-backed comparisons, what-if calculator, policy-bounded negotiation, booking/CRM/handoff.
Stack: Next.js + TypeScript + React Flow; FastAPI + FastMCP + Pydantic; Supabase/Postgres + optional Graphiti; Langfuse + Promptfoo + Presidio.
